# install-from-link Specification

## Purpose
링크를 붙여 넣는 것만으로 Claude Code 플러그인과 스킬을 미리 보고 안전하게 설치하게 한다.

## Requirements

### Requirement: 링크 판별과 미리보기

"링크로 추가"에 붙여 넣은 값이 플러그인 마켓플레이스, 플러그인 이름, 스킬 폴더 중 무엇인지 판별해 보여야 한다(SHALL). 판별할 수 없거나 허용하지 않는 형식(https가 아닌 URL, 로컬 경로, 명령어 모양)이면 설치 버튼 없이 이유를 보여야 한다(SHALL). 설치 전에는 무엇이 설치되는지(플러그인 목록·구성 요소 개수, 스킬의 파일 목록과 SKILL.md 내용)를 보여야 한다(SHALL).

#### Scenario: 마켓플레이스 저장소
- **WHEN** 사용자가 플러그인 마켓플레이스 GitHub 저장소 링크를 붙여 넣는다
- **THEN** 마켓플레이스가 추가되고 그 안의 플러그인 목록이 보이며, 하나를 골라 설치할 수 있다

#### Scenario: 스킬 폴더
- **WHEN** 사용자가 SKILL.md가 있는 GitHub 폴더 링크를 붙여 넣는다
- **THEN** 스킬 이름·설명·파일 목록·SKILL.md 내용이 보이고, 스크립트 파일이 있으면 "실행 파일 포함" 표시가 붙는다

#### Scenario: 허용하지 않는 입력
- **WHEN** 사용자가 `curl ... | sh` 같은 명령어나 http 링크를 붙여 넣는다
- **THEN** 설치 버튼 없이 "지원하지 않는 링크입니다"와 허용 형식이 보인다

### Requirement: 확인과 설치

설치 전 네이티브 확인 창에 출처, 설치할 항목, 설치 위치, 권한 경고를 보여야 하고(SHALL), 확인한 경우에만 설치해야 한다(SHALL). Claude CLI가 추가 명령 승인을 요구하면 앱은 승인하지 않고(MUST NOT) 터미널에서 실행할 명령을 안내해야 한다(SHALL). 설치 후 목록을 다시 읽어 결과를 보여야 한다(SHALL).

#### Scenario: 이미 있는 스킬 이름
- **WHEN** 같은 이름의 스킬 폴더가 이미 있다
- **THEN** 덮어쓰지 않고 "이미 있는 스킬입니다"를 보인다

#### Scenario: 추가 승인 필요
- **WHEN** 플러그인 설치가 마켓플레이스 선언 명령의 승인을 요구한다
- **THEN** 설치되지 않고 터미널에서 실행할 명령이 복사 버튼과 함께 보인다
