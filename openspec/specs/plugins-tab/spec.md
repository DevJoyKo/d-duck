# plugins-tab Specification

## Purpose
설치된 Claude Code 플러그인과 그 안의 스킬·커맨드를 한곳에서 보고, 켜고 끄고 업데이트하게 한다.

## Requirements

### Requirement: 플러그인 목록

플러그인 탭은 설치된 플러그인마다 이름, 마켓플레이스, 버전, 범위, 켜짐 여부, 마지막 갱신일, 구성 요소(스킬·커맨드·에이전트·훅·MCP 서버) 개수를 보여야 한다(SHALL). 펼치면 스킬과 커맨드의 이름·설명·사용 횟수를 보여야 한다(SHALL). 플러그인 파일 내용·설정 값·MCP 서버 주소의 인증 정보는 보이거나 저장하지 않는다(MUST NOT).

#### Scenario: 플러그인 펼치기
- **WHEN** 사용자가 스킬 3개와 커맨드 2개가 든 플러그인을 펼친다
- **THEN** 다섯 항목이 종류별로 이름·설명·사용 횟수와 함께 보인다

### Requirement: 켜기와 끄기

사용자는 각 플러그인을 켜거나 끌 수 있어야 하며(SHALL), 결과는 Claude Code 설정에 반영되고 "Claude Code를 다시 시작하면 적용됩니다"가 보여야 한다(SHALL). 관리자 설정으로 강제된 플러그인은 토글이 잠기고 이유가 보인다(SHALL).

#### Scenario: 끄기
- **WHEN** 사용자가 켜진 플러그인의 토글을 끈다
- **THEN** 플러그인이 꺼짐으로 표시되고 다시 목록을 불러와도 꺼져 있다

### Requirement: 업데이트

마켓플레이스에 더 새 버전이 있으면 업데이트 버튼이 활성화되어야 한다(SHALL). 업데이트 전 네이티브 확인 창에 현재 → 새 버전을 보여야 하고(SHALL), CLI가 추가 명령 승인을 요구하면 앱은 자동 승인하지 않고 터미널에서 하라고 안내해야 한다(MUST).

#### Scenario: 새 버전
- **WHEN** 설치 1.0.2, 마켓플레이스 1.0.3이다
- **THEN** "1.0.3으로 업데이트"가 활성이고, 확인하면 업데이트 후 버전이 1.0.3으로 바뀐다

#### Scenario: 추가 승인 필요
- **WHEN** 업데이트가 마켓플레이스 선언 명령 승인을 요구한다
- **THEN** 아무것도 실행되지 않고 "터미널에서 claude plugin update로 진행하세요"가 보인다
