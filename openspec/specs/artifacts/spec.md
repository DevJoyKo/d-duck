# artifacts Specification

## Purpose
이 기기의 Claude Code 기록에 남은 아티팩트 게시 결과를 모아, 사용자가 최근에 만든 아티팩트를 찾고 열 수 있게 한다.

## Requirements

### Requirement: 아티팩트 수집
앱은 사용 기록을 수집할 때 아티팩트 게시·생성 결과(링크, 제목, 종류, 게시 순번, 기록 시각)와 그것이 나온 세션을 저장해야 한다(SHALL). 링크가 `https://claude.ai/artifact/<id>` 또는 `https://claude.ai/code/artifact/<id>` 형식이고 아티팩트 버전 표식이 있는 결과만 저장해야 하며(SHALL), 그 밖의 결과 필드(로컬 경로, 지침 등)는 읽지 않아야 한다(MUST NOT). 같은 링크가 여러 번 게시되면 하나로 합치고 가장 높은 순번과 가장 최근 시각을 남겨야 한다(SHALL).

#### Scenario: 여러 번 게시한 아티팩트
- **WHEN** 한 아티팩트가 순번 2, 3, 4로 세 번 게시되었다
- **THEN** 목록에는 그 아티팩트가 한 번만 나오고 버전 4와 마지막 게시 시각이 표시된다

#### Scenario: 다른 도구의 링크
- **WHEN** 웹 페이지 가져오기 결과에 claude.ai 아티팩트 링크가 들어 있다
- **THEN** 그 결과는 아티팩트로 저장되지 않는다

#### Scenario: 결과의 다른 필드
- **WHEN** 게시 결과에 로컬 파일 경로와 지침 텍스트가 함께 들어 있다
- **THEN** 앱 DB와 로그 어디에도 그 경로와 텍스트가 남지 않는다

#### Scenario: 형식이 다른 링크
- **WHEN** 게시 결과의 링크가 claude.ai 아티팩트 형식이 아니다
- **THEN** 그 결과는 저장되지 않는다

### Requirement: 아티팩트 목록
아티팩트 페이지는 수집된 아티팩트를 마지막 게시 시각 최신순으로 카드로 보여야 하며(SHALL), 카드에는 미리보기, 제목, 종류, 버전, 마지막 게시 시각, 프로젝트가 있어야 한다(SHALL). 한 페이지의 카드 수는 고정값이 아니라 창 크기에 맞춰 정해야 하며(SHALL), 목록 영역 안에 잘리지 않고 들어가는 열 수 × 행 수(최소 1행, 열은 카드 최소 폭 기준)여야 한다(SHALL). 창 크기가 바뀌면 다시 계산하되, 보고 있던 첫 카드가 포함된 페이지로 이동해야 한다(SHALL). 이전·다음·페이지 번호로 넘길 수 있어야 한다(SHALL). 제목 검색을 제공해야 하며 검색어가 바뀌면 첫 페이지로 돌아가야 한다(SHALL). 수집된 아티팩트가 없으면 이유와 함께 빈 상태를 보여야 한다(SHALL).

#### Scenario: 제목 검색
- **WHEN** 사용자가 3쪽을 보다가 검색창에 "대시보드"를 입력한다
- **THEN** 제목에 "대시보드"가 들어간 아티팩트만 1쪽부터 보인다

#### Scenario: 페이지 넘기기
- **WHEN** 아티팩트가 23개이고 창 크기로 계산한 한 페이지 카드 수가 8개다
- **THEN** 1쪽에 카드 8개, 페이지 표시 "1 / 3"이 보이고, 다음을 누르면 9~16번째가, 3쪽에는 7개가 보인다

#### Scenario: 창 크기에 맞춤
- **WHEN** 1440×900 창과 900×700 창에서 아티팩트 탭을 연다
- **THEN** 두 창 모두 마지막 행의 카드가 아래로 잘리지 않고 페이지 넘김 막대가 보이며, 큰 창에서 한 페이지 카드 수가 더 많다

#### Scenario: 창 크기 변경
- **WHEN** 2쪽을 보다가 창을 줄여 한 페이지 카드 수가 줄어든다
- **THEN** 보고 있던 첫 카드가 포함된 페이지로 이동하고 그 카드가 보인다

#### Scenario: 아티팩트 없음
- **WHEN** 이 기기에서 만든 아티팩트가 없다
- **THEN** "이 기기에서 만든 아티팩트가 아직 없습니다" 안내가 보인다

### Requirement: 아티팩트 열기
사용자는 아티팩트를 기본 브라우저로 열고 링크를 복사할 수 있어야 한다(SHALL). 앱은 수집해 둔 아티팩트의 링크만 열어야 하며, 웹뷰가 보낸 임의의 URL은 열지 않아야 한다(MUST NOT).

#### Scenario: 브라우저로 열기
- **WHEN** 사용자가 아티팩트의 "열기"를 누른다
- **THEN** 기본 브라우저에서 그 아티팩트 링크가 열린다

#### Scenario: 임의 URL 거부
- **WHEN** 웹뷰가 수집되지 않은 ID로 열기를 요청한다
- **THEN** 아무것도 열지 않고 오류를 돌려준다

### Requirement: 제목 저장 설정 연동
아티팩트 제목은 세션 제목과 같은 "세션 제목 저장" 설정을 따라야 한다(SHALL). 설정을 끄면 저장된 아티팩트 제목도 지우고 ID 앞부분을 대신 보여야 한다(SHALL).

#### Scenario: 제목 저장 끄기
- **WHEN** 사용자가 세션 제목 저장을 끈다
- **THEN** 아티팩트 목록의 제목이 아티팩트 ID 앞부분으로 바뀐다

### Requirement: 사이드바 메뉴
사이드바 위쪽 "작업" 아래에 "아티팩트" 메뉴를 두어야 한다(SHALL).

#### Scenario: 메뉴 이동
- **WHEN** 사용자가 사이드바의 "아티팩트"를 누른다
- **THEN** 아티팩트 페이지가 열린다

### Requirement: 카드 미리보기
카드는 아티팩트를 마지막으로 게시할 때 쓴 로컬 원본 파일이 남아 있으면 그 내용을 축소해 보여야 한다(SHALL). 원본 위치는 그 세션 기록의 Artifact 도구 호출 입력에서 현재 페이지의 카드에 대해서만 찾아야 하며(SHALL), 경로와 내용을 DB·로그에 저장하지 않아야 한다(MUST NOT). 미리보기는 스크립트를 실행하지 않고 네트워크 요청을 보내지 않아야 한다(MUST NOT). 타입 아티팩트는 미리보기 없음으로 표시해야 한다(SHALL). 원본은 홈 폴더(또는 본인 Claude 임시 폴더) 안의 일반 파일(링크 아님)이며 확장자가 `.html`·`.htm`·`.md`이고 2MB 이하일 때만 읽어야 한다(SHALL). 그렇지 않으면 "미리보기 없음"과 이유를 보여야 한다(SHALL).

#### Scenario: 로컬 HTML 원본이 있음
- **WHEN** 아티팩트가 `~/proj/report.html`에서 게시되었고 파일이 남아 있다
- **THEN** 카드에 그 페이지가 축소되어 보이고, 페이지 안 스크립트는 실행되지 않는다

#### Scenario: 원본이 지워짐
- **WHEN** 원본 파일이 삭제되었다
- **THEN** 카드에 종류 아이콘과 "미리보기 없음 · 원본 파일이 없습니다"가 보이고 열기·링크 버튼은 그대로 동작한다

#### Scenario: 위험한 경로
- **WHEN** 기록의 원본 경로가 심볼릭 링크이거나 홈 폴더 밖이거나 확장자가 다르다
- **THEN** 파일을 읽지 않고 "미리보기 없음"이 보인다
