# usage-analytics Specification

## Purpose
수집된 Claude Code 사용 데이터를 기간, 모델, 프로젝트, 툴, 스킬 기준으로 집계해 사용자가 자신의 사용 패턴과 비용을 파악하게 하는 통계 화면을 정의한다.

## Requirements

### Requirement: 기간 선택
사용 통계 탭은 오늘, 최근 7일, 최근 30일, 전체, 사용자 지정 기간을 선택할 수 있어야 한다(SHALL). 기본값은 최근 7일이다. 기간 경계는 사용자의 로컬 시간대로 계산해야 한다(SHALL).

#### Scenario: 기간 변경
- **WHEN** 사용자가 기간을 "최근 30일"로 바꾼다
- **THEN** 탭의 모든 수치와 차트가 30일 범위로 다시 계산된다

### Requirement: 요약 지표
선택한 기간의 총 토큰(유형별), 추정 비용(USD), 세션 수, API 응답 수, 툴 호출 수, 스킬 호출 수를 요약 카드로 보여야 한다(SHALL).

#### Scenario: 데이터 없음
- **WHEN** 선택한 기간에 수집된 데이터가 없다
- **THEN** 요약 카드는 0을 표시하고 "이 기간의 사용 기록이 없습니다" 안내가 나타난다

### Requirement: 시계열 추이
기간 내 일별(기간이 2일 이하면 시간별) 토큰 사용량과 추정 비용 추이를 차트로 보여야 한다(SHALL). 토큰은 유형별로 구분해야 한다(SHALL).

#### Scenario: 오늘 선택
- **WHEN** 기간이 "오늘"이다
- **THEN** 추이 차트가 시간 단위로 표시된다

### Requirement: 분포 분석
모델별, 프로젝트별, 툴별, 스킬별, 내장 명령별, MCP 서버별, 서브에이전트 유형별 사용량을 정렬된 목록 또는 차트로 보여야 한다(SHALL). 각 항목은 호출 수와 비중(%)을 함께 표시해야 한다(SHALL).

#### Scenario: 툴 Top N
- **WHEN** 사용자가 툴 분포를 연다
- **THEN** 호출 수 기준 내림차순으로 상위 10개 툴과 "기타" 합계가 표시된다

#### Scenario: 스킬 호출 경로
- **WHEN** 사용자가 스킬 분포를 연다
- **THEN** 스킬별 호출 수가 Skill 도구 호출과 슬래시 명령 호출로 구분되어 표시된다

#### Scenario: 내장 명령 분리
- **WHEN** 기간 내 `/upgrade` 2회와 `/opsx:propose` 1회가 기록되어 있다
- **THEN** 스킬 분포에는 `opsx:propose`만, 명령 분포에는 `/upgrade`가 표시된다

### Requirement: 필터
프로젝트와 모델로 필터링할 수 있어야 하며(SHALL), 필터는 요약·추이·분포 전체에 함께 적용되어야 한다(SHALL).

#### Scenario: 프로젝트 필터
- **WHEN** 사용자가 프로젝트 "dev_team"만 선택한다
- **THEN** 모든 지표가 해당 프로젝트 세션만으로 다시 계산된다

### Requirement: 비용 추정
추정 비용은 모델별 단가표로 계산하고(SHALL), 화면에 "추정치"임을 표시해야 한다(SHALL). 단가표에 없는 모델은 비용 0으로 두고 "단가 미등록" 표시를 해야 한다(SHALL). 세션 단위로 기록된 공식 누적 비용이 있으면 세션 상세에서 함께 보여야 한다(SHALL).

#### Scenario: 미등록 모델
- **WHEN** 단가표에 없는 모델의 응답이 수집되어 있다
- **THEN** 해당 모델 행에 "단가 미등록"이 표시되고 총 비용에는 포함되지 않는다

### Requirement: 세션 목록과 상세
기간 내 세션을 최근순으로 나열하고(SHALL), 세션을 선택하면 제목, 프로젝트, 브랜치, 시작·종료 시각, 모델별 토큰, 추정 비용, 툴·스킬 호출 집계를 보여야 한다(SHALL).

#### Scenario: 세션 상세 열기
- **WHEN** 사용자가 세션 목록에서 한 세션을 선택한다
- **THEN** 그 세션의 토큰·비용·툴·스킬 집계가 표시되고, 메시지 원문은 표시되지 않는다
