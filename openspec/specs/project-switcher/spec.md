## Requirements

### Requirement: 탭별 프로젝트 선택기 (D-127, 사이드바 선택기 대체)
범위가 있는 탭(권한·메모리·확장·MCP)마다 제목 아래 같은 자리에 프로젝트 선택기가 있어야 하며(SHALL), 사이드바에는 프로젝트 선택기를 두지 않는다(MUST NOT). 탭마다 고른 프로젝트를 따로 기억해야 한다(SHALL). 폴더 이름을 보여 주고, 누르면 최근 사용 순 목록과 이름 검색, "프로젝트 없음(전역만)"을 제공해야 한다(SHALL). 고른 값은 앱을 다시 열어도 유지되어야 하며(SHALL), 앱이 아는 프로젝트만 고를 수 있어야 한다(SHALL).

#### Scenario: 프로젝트 바꾸기
- **WHEN** 사용자가 권한 탭의 선택기에서 dev_team을 고른다
- **THEN** 권한 탭만 dev_team 기준으로 바뀌고 다른 탭은 각자 고른 프로젝트를 유지하며, 앱을 다시 열어도 권한 탭은 dev_team이다

### Requirement: 같은 자리의 범위 전환
범위가 있는 화면은 제목 바로 아래 같은 자리에 같은 모양의 [전역 | 프로젝트 이름] 전환을 보여야 하며(SHALL), 화면 안에 별도의 프로젝트 드롭다운을 두지 않아야 한다(MUST NOT). 프로젝트가 없으면 프로젝트 쪽은 "프로젝트 고르기"로 보이고 누르면 사이드바 선택기가 열려야 한다(SHALL).

#### Scenario: 프로젝트 없이 권한 화면
- **WHEN** 현재 프로젝트가 없는 상태로 권한 화면을 연다
- **THEN** [전역 | 프로젝트 고르기]가 보이고, 프로젝트 고르기를 누르면 그 탭의 선택기가 열린다

### Requirement: 홈 폴더
현재 프로젝트가 홈 폴더면 프로젝트 범위를 끄고 "홈 폴더는 전역과 같아요"를 보여야 한다(SHALL). 홈의 규칙·설정을 프로젝트 쪽에서 다시 나열하거나 고치지 않아야 한다(MUST NOT).

#### Scenario: 홈을 고름
- **WHEN** 사용자가 홈 폴더를 현재 프로젝트로 고르고 규칙 화면을 연다
- **THEN** 전역 규칙만 보이고 프로젝트 쪽에는 "홈 폴더는 전역과 같아요"가 보인다
