# sessions-skills-connectors Specification

## Purpose
사용 통계의 세션을 전부 넘겨 보고 한 세션의 흐름을 분석하게 하며, 세션 제목을 고치고, 로컬 스킬과 커넥터를 한눈에 보게 한다.

## Requirements

### Requirement: 세션 목록 페이지
세션 목록은 위쪽 통계의 기간과 별도로 기간(전체·오늘·7일·30일, 기본 전체)을 가져야 한다(SHALL). 한 페이지에 10개씩 최근 활동순으로 보여야 하고(SHALL), 총 개수와 이전·다음 이동을 제공해야 한다(SHALL). 프로젝트·모델 필터는 목록에도 적용한다.

#### Scenario: 전체 세션
- **WHEN** 기록에 세션이 34개 있고 사용자가 사용 통계를 연다
- **THEN** 세션 목록에 10개가 보이고 "1–10 / 34"와 다음 버튼이 있으며, 다음을 누르면 11–20이 보인다

### Requirement: 세션 타임라인
세션을 열면 그 세션의 transcript를 그때 읽어 시간순 타임라인을 보여야 한다(SHALL). 항목은 사용자 프롬프트(항목당 2000자), Claude 응답 텍스트(메시지당 앞 400자), 도구 호출(도구 이름, 입력 요약 160자, 결과 성공·오류와 오류 첫 줄 160자; 서브에이전트 시작은 Agent 호출의 유형과 설명), 대화 압축 표시다. 비밀값처럼 보이는 문자열(키·토큰·인증 헤더·`key=값`·URL 인증 정보와 쿼리·40자 이상 덩어리)은 자르기 전에 가려야 한다(SHALL). 사고 블록과 도구 결과 본문은 보이지 않아야 한다(MUST NOT). 타임라인은 저장·기록·캐시하지 않아야 하며(MUST NOT), 기록이 길면 마지막 32MB와 최근 2000개 항목만 읽고 "최근 부분만 보여 줍니다"를 알려야 한다(SHALL). 전체·프롬프트·도구·오류 필터를 둔다(SHALL).

#### Scenario: 도구 호출 확인
- **WHEN** 사용자가 Bash 호출 12번이 있는 세션을 열고 "도구" 필터를 고른다
- **THEN** 도구 호출 항목만 시간순으로 보이고 각 항목에 명령 요약과 성공·오류가 표시된다

#### Scenario: 비밀처럼 보이는 내용
- **WHEN** 도구 입력에 긴 토큰 문자열이 있다
- **THEN** 화면에는 요약 길이까지만 보이고 D.Duck DB와 로그에는 아무것도 남지 않는다

### Requirement: 세션 제목 수정
세션 목록과 세션 상세의 이름 옆 연필 아이콘으로 제목을 고칠 수 있어야 한다(SHALL). 저장한 제목은 Claude가 붙인 제목보다 우선해 사용 통계와 작업 보드에 보여야 하며(SHALL), 비우고 저장하면 원래 제목으로 돌아가야 한다(SHALL). 제목은 1–80자, 제어·bidi 문자는 거부한다(SHALL). Enter로 저장하고 Esc로 취소한다.

#### Scenario: 제목 고치기
- **WHEN** 사용자가 세션 "c3000000"의 연필을 눌러 "노트북 정리"를 입력하고 Enter를 누른다
- **THEN** 목록과 상세에 "노트북 정리"가 보이고 앱을 다시 켜도 유지된다

#### Scenario: 제목 저장 끄기와의 관계
- **WHEN** 설정에서 "세션 제목 저장"을 끈다
- **THEN** Claude가 붙인 제목은 지워지지만 사용자가 직접 붙인 제목은 남는다

### Requirement: 스킬 목록
사이드바에 "스킬" 메뉴를 두고, 사용자·프로젝트·플러그인 스킬과 명령을 모아 이름, 출처, 설명, 사용 횟수(슬래시·도구 호출 합), 마지막 사용 시각과 함께 보여야 한다(SHALL). 사용 기록만 있고 정의를 찾지 못한 스킬도 "정의 없음"으로 보여야 한다(SHALL). 이름 검색과 출처 필터를 제공한다. 스킬 파일 내용은 설명 줄 외에는 읽어 보내지 않는다(SHALL).

#### Scenario: 많이 쓴 스킬
- **WHEN** 사용자가 스킬 페이지를 연다
- **THEN** 스킬이 사용 횟수 순으로 보이고 각 항목에 출처와 마지막 사용 시각이 있다

### Requirement: 커넥터 목록
설정 페이지에 커넥터 영역을 두고, "연결 상태 확인"을 누를 때만 `claude mcp list`를 실행해 이름, 종류(원격·로컬·claude.ai·플러그인), 원격이면 호스트, 상태(연결됨·인증 필요·실패·기타)를 보여야 한다(SHALL). 명령, 인자, 환경 변수, 헤더, 주소의 경로와 쿼리는 파싱 단계에서 버려야 한다(MUST NOT 표시·저장). 결과는 메모리에만 두고 마지막 확인 시각을 보여 준다. 인증 필요 항목에는 "Claude Code에서 /mcp로 인증" 안내를 붙인다.

#### Scenario: 상태 확인
- **WHEN** 사용자가 "연결 상태 확인"을 누른다
- **THEN** 커넥터마다 이름과 상태가 보이고, 로컬 커넥터에는 실행 명령이 보이지 않는다

#### Scenario: 긴 세션
- **WHEN** 기록 파일이 40MB인 세션을 연다
- **THEN** 최근 항목이 보이고 "최근 부분만 보여 줍니다"가 표시된다
