# onboarding-tour Specification

## Purpose
처음 D.Duck을 켠 사용자가 각 탭에서 무엇을 할 수 있는지 하나씩 알고 첫 작업까지 해 보게 한다.

## Requirements

### Requirement: 첫 실행 안내

앱을 처음 켜면 환영 화면이 Claude CLI 상태와 함께 보여야 하고(SHALL), 사용자는 둘러보기를 시작하거나 나중으로 미룰 수 있어야 한다(SHALL). 한 번 끝내거나 건너뛰면 다시 자동으로 뜨지 않아야 한다(SHALL).

#### Scenario: 처음 켜기
- **WHEN** 사용자가 설치 후 처음 앱을 켠다
- **THEN** 환영 화면이 뜨고 "둘러보기 시작"을 누르면 첫 카드(에이전트)가 보이며, 카드를 클릭할 때마다 다음 기능 카드로 넘어간다

### Requirement: 카드 넘기기 튜토리얼

튜토리얼은 기능마다 카드 한 장(오리 그림·작은 도식·제목·할 수 있는 일·해 볼 일)을 보여 주고, 카드를 클릭하거나 →·스페이스를 누르면 다음 카드로 넘어가야 한다(SHALL). 이전·건너뛰기·점 진행 표시가 있어야 하고(SHALL), 카드의 "이 화면 열기"를 누르면 튜토리얼을 닫고 그 탭으로 이동해야 한다(SHALL).

#### Scenario: 건너뛰기
- **WHEN** 사용자가 3번째 카드에서 Esc를 누른다
- **THEN** 튜토리얼이 닫히고 원래 보던 화면으로 돌아오며 설정에서 다시 볼 수 있다

### Requirement: 시작하기 체크리스트

둘러보기 뒤에는 시작하기 체크리스트가 보여야 하고(SHALL), 항목은 사용자가 실제로 그 일을 하면 자동으로 체크되어야 한다(SHALL). 체크리스트는 접을 수 있어야 하고(SHALL), 세 항목을 모두 하면 저절로 사라져야 한다(SHALL).

#### Scenario: 첫 작업 맡기기
- **WHEN** 사용자가 작업 탭에서 새 작업을 시작한다
- **THEN** 체크리스트의 "첫 작업 맡기기"가 체크된다

### Requirement: 다시 보기와 새 단계

설정에서 언제든 둘러보기를 다시 볼 수 있어야 하고(SHALL), 앱 업데이트로 새 탭이 생기면 그 단계만 한 번 안내해야 한다(SHALL).

#### Scenario: 새 탭 안내
- **WHEN** 둘러보기를 끝낸 사용자가 메모리 탭이 추가된 버전으로 업데이트한다
- **THEN** 다음 실행 때 메모리 탭 단계 하나만 안내된다
