# Spec Delta

## ADDED Requirements

### Requirement: 루틴 실행 보고서의 칸
보고서가 붙은 루틴 실행은 작업 기록과 같은 칸 규칙을 따라야 한다(SHALL): 끝났고 리뷰하지 않았고 리뷰 기준 시각 이후면 리뷰 대기, 리뷰했고 정리 끝을 누르지 않았으면 정리, 정리 끝이면 보드에서 빠짐. 리뷰 대기 칸 수는 리뷰 탭 배지와 같아야 한다(SHALL, 루틴 포함). 정리 끝·끝내고 넘기기·되돌리기는 루틴 실행에도 그 실행의 값으로 저장되어야 한다(SHALL). 리뷰하지 않은 루틴 보고서는 정리 끝을 거절해야 한다(SHALL). 보고서가 없는 루틴 실행은 지금처럼 리뷰 대상이 아닌 세션으로 다룬다(SHALL). 예전에 세션 키로 정리 끝 한 루틴 실행은 목록에서 그 세션을 볼 때 정리 끝으로 옮겨야 하고(SHALL), 정리 끝인 기록은 리뷰 대기·리뷰 전에 들지 않아야 한다(MUST NOT). 보고서가 붙은 루틴 실행이 끝나면 완료 알림과 트레이도 리뷰 대기로 말해야 한다(SHALL). 루틴 실행에는 worktree가 없으므로 정리 점검표는 "확인 못 했어요"여도 된다(MAY).

#### Scenario: 루틴 리뷰 대기
- **WHEN** 기준 시각 이후 루틴 실행이 보고서를 남기고 끝났고 목록에서도 사라졌다
- **THEN** 리뷰 대기 칸에 그 카드가 루틴 이름으로 보이고 칸 수가 리뷰 탭 배지와 같다

#### Scenario: 루틴 정리 끝
- **WHEN** 사용자가 리뷰한 루틴 실행 카드의 "정리 끝"을 누른다
- **THEN** 카드가 보드에서 빠지고, 5초 안 "되돌리기"를 누르면 정리 칸으로 돌아온다

#### Scenario: 예전에 정리 끝 한 루틴
- **WHEN** 업데이트 전에 정리 끝을 누른 루틴 실행(보고서 있음)이 아직 작업 목록에 있다
- **THEN** 리뷰 대기 칸·리뷰 탭 배지에 들지 않고 보드에서 빠진 채로 있다

#### Scenario: 루틴 완료 알림
- **WHEN** 기준 시각 이후 보고서가 붙은 루틴 실행이 끝난다
- **THEN** 완료 알림이 "리뷰 대기"를 말하고 트레이 툴팁 리뷰 대기 수가 1 는다
