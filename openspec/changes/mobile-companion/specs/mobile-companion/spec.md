# Spec Delta

## Purpose

사용자가 휴대폰으로 D.Duck의 에이전트·작업 상태를 안전하게 볼 수 있게 한다. 데이터는 Mac과 사용자의 Tailscale 기기 사이에서만 오간다.

## ADDED Requirements

### Requirement: 휴대폰 보기 서버
설정에 "휴대폰에서 보기"(기본 꺼짐)를 두어야 한다(SHALL). 켜면 D.Duck은 `127.0.0.1`의 고정 포트에서만 듣는 읽기 전용 HTTP 서버를 띄워야 하며(SHALL), 다른 네트워크 주소에서 듣지 않아야 한다(MUST NOT). 서버는 GET 요청만 받고 상태를 바꾸는 요청은 페어링 하나뿐이어야 한다(SHALL). 끄면 서버를 멈추고 모든 연결을 끊어야 한다(SHALL).

#### Scenario: 켜고 끄기
- **WHEN** 사용자가 설정에서 "휴대폰에서 보기"를 켠다
- **THEN** `127.0.0.1:<포트>`에서 서버가 응답하고, 끄면 같은 주소로 연결할 수 없다

#### Scenario: 외부 주소
- **WHEN** 같은 Wi-Fi의 다른 기기가 Mac의 LAN 주소와 그 포트로 접속한다
- **THEN** 연결되지 않는다

### Requirement: 기기 연결
API 요청은 연결된 기기의 토큰(`Authorization: Bearer`)이 있어야 하며 없거나 틀리면 401이어야 한다(SHALL). Mac 설정 화면은 5분 동안 한 번만 쓸 수 있는 6자리 코드와 접속 주소 QR을 보여 주고, 휴대폰이 코드를 입력하면 그 기기용 무작위 토큰을 발급해야 한다(SHALL). 토큰은 해시로만 저장해야 한다(SHALL). 코드 입력은 5번 틀리면 그 코드를 폐기해야 한다(SHALL). 설정에서 연결된 기기를 이름·마지막 접속 시각과 함께 보고 끊을 수 있어야 한다(SHALL).

#### Scenario: 휴대폰 연결
- **WHEN** 사용자가 Mac에 표시된 코드를 휴대폰 웹앱에 입력한다
- **THEN** 휴대폰이 홈 화면을 보고, Mac 설정의 연결된 기기에 그 휴대폰이 나타난다

#### Scenario: 기기 끊기
- **WHEN** 사용자가 Mac에서 그 기기를 끊는다
- **THEN** 휴대폰의 다음 요청이 401을 받고 다시 연결 화면이 보인다

#### Scenario: 코드 추측
- **WHEN** 틀린 코드가 5번 입력된다
- **THEN** 그 코드는 더 쓸 수 없고 Mac에서 새 코드를 만들어야 한다

### Requirement: 모바일 웹앱
휴대폰 웹앱은 홈(막힌 작업 수와 목록, 일하는 agent와 상태 문장, 검토 용량), 작업(대기·진행·검토 필요·완료 열과 각 작업의 유형·페르소나·처음 지시), 지난 작업(이름·폴더·유형·시각, 누르면 지시), 루틴(로컬 루틴 이름·일정·다음 실행·마지막 결과), 오늘 사용량(비용·토큰·응답 수)을 보여야 한다(SHALL). 15초마다 새로 고치고, Mac에 연결할 수 없으면 마지막으로 받은 시각과 함께 "Mac에 연결할 수 없습니다"를 보여야 한다(SHALL). 홈 화면에 추가할 수 있어야 한다(SHALL). 웹앱은 상태를 바꾸는 버튼을 두지 않는다.

#### Scenario: 막힌 작업 확인
- **WHEN** Mac에서 작업 2개가 답을 기다린다
- **THEN** 휴대폰 홈 맨 위에 "막힌 작업 2개"와 그 작업 이름이 보인다

#### Scenario: Mac 꺼짐
- **WHEN** Mac이 잠들어 응답하지 않는다
- **THEN** 휴대폰은 마지막 화면을 유지하고 "Mac에 연결할 수 없습니다 · 마지막 <시각>"을 보인다

### Requirement: 응답 내용 제한
API는 화면에 필요한 값만 보내야 한다(SHALL). transcript 원문, 세션 흐름, Claude 자격증명, 설정 경로, 루틴 지시문은 보내지 않아야 한다(MUST NOT). 처음 지시와 지난 작업의 지시는 D.Duck이 이미 보여 주는 값과 같은 것만 보낸다.

#### Scenario: 루틴 지시
- **WHEN** 휴대폰이 루틴 목록을 받는다
- **THEN** 응답에 루틴 지시문은 없고 이름·일정·다음 실행·마지막 결과만 있다

### Requirement: Tailscale 연결 안내
설정의 휴대폰 영역은 Tailscale 설치·로그인 여부를 감지해 안내해야 하고(SHALL), "Tailscale로 공개" 버튼으로 `tailscale serve`를 이 포트에 연결하기 전 네이티브 확인을 받아야 한다(SHALL). 연결되면 휴대폰 접속 주소(`https://<기기>.<tailnet>.ts.net`)와 QR을 보여야 한다(SHALL). Tailscale이 없으면 설치 안내만 보이고 서버는 Mac 안에서만 접근할 수 있다.

#### Scenario: Tailscale 없음
- **WHEN** Tailscale이 설치되지 않은 Mac에서 휴대폰 영역을 연다
- **THEN** 설치·로그인 단계 안내가 보이고 휴대폰 주소는 표시되지 않는다
