# Spec Delta

## MODIFIED Requirements

### Requirement: 업데이트

마켓플레이스에 더 새 버전이 있으면 업데이트 버튼이 활성화되어야 한다(SHALL). 업데이트 전 네이티브 확인 창에 현재 → 새 버전을 보여야 하고(SHALL), CLI가 추가 명령 승인을 요구하면 앱은 자동 승인하지 않고 터미널에서 하라고 안내해야 한다(MUST).

플러그인 묶음 머리에는 "모두 업데이트 (N)"와 "선택한 것 업데이트 (N)"가 있어야 한다(SHALL). 앱에서 바꿀 수 있는(전역 범위) 플러그인 가운데 업데이트 있음 또는 확인 불가인 줄에만 체크박스가 있어야 하고(SHALL), 최신이거나 잠긴(프로젝트·로컬·관리자·알 수 없는 범위) 플러그인은 고를 수 없어야 한다(MUST NOT). "모두"는 업데이트 있음만 대상으로 해야 한다(SHALL). 한 번에 15개까지 고를 수 있어야 하고(SHALL) 확인 창에 적히지 않은 플러그인은 실행하지 않아야 한다(MUST NOT). 한꺼번에 업데이트는 네이티브 확인 창 하나를 거쳐야 하며(SHALL), 창은 대상 플러그인마다 빠짐없이 이름@마켓플레이스·범위·현재 → 새 버전(모르면 확인 불가)과 단일 업데이트와 같은 위험 안내를 보여야 한다(SHALL). 대상·범위·버전은 웹뷰 값이 아니라 다시 읽은 CLI 목록으로 정하고, 확인 창이 열린 동안이나 앞 항목이 도는 동안 바뀐 플러그인은 건너뛰어야 한다(SHALL). 진행 상태는 다른 탭에 갔다 와도 보여야 한다(SHALL). 업데이트는 하나씩 차례로, 플러그인마다 따로 시간 제한을 두고 단일 업데이트와 같은 명령으로 실행해야 한다(SHALL, `-y`·`--accept-command` 금지 MUST NOT). 줄마다 대기·업데이트 중·완료·실패(이유)가 보여야 하고(SHALL), 하나가 실패하거나 승인이 필요해도 나머지는 계속해야 한다(SHALL). "멈추기"는 지금 업데이트 중인 것을 끝낸 뒤 남은 것을 실행하지 않아야 한다(SHALL). 끝나면 목록을 다시 읽고 요약 한 줄을 보여야 한다(SHALL). 진행 중에는 다른 켜기·끄기·업데이트를 받지 않아야 한다(SHALL).

#### Scenario: 새 버전
- **WHEN** 설치 1.0.2, 마켓플레이스 1.0.3이다
- **THEN** "1.0.3으로 업데이트"가 활성이고, 확인하면 업데이트 후 버전이 1.0.3으로 바뀐다

#### Scenario: 추가 승인 필요
- **WHEN** 업데이트가 마켓플레이스 선언 명령 승인을 요구한다
- **THEN** 아무것도 실행되지 않고 "터미널에서 claude plugin update로 진행하세요"가 보인다

#### Scenario: 모두 업데이트
- **WHEN** 업데이트 있음 3개, 확인 불가 1개, 최신 2개, 관리자 범위 1개가 있다
- **THEN** "모두 업데이트 (3)"이고, 확인 창에 세 플러그인이 현재 → 새 버전과 함께 적히며, 확인하면 하나씩 업데이트 중 → 완료로 바뀐다

#### Scenario: 선택한 것 업데이트
- **WHEN** 확인 불가 1개와 업데이트 있음 1개를 체크한다
- **THEN** "선택한 것 업데이트 (2)"가 활성이고 확인 창에 두 개만 적힌다. 최신·관리자 범위 줄에는 체크박스가 없다

#### Scenario: 하나 실패
- **WHEN** 세 개 가운데 두 번째가 실패한다
- **THEN** 두 번째 줄에 "실패했어요 · 이유"가 보이고 세 번째도 업데이트되며, 요약은 "2개 업데이트, 1개 실패"다

#### Scenario: 멈추기
- **WHEN** 세 개 가운데 첫 번째가 업데이트 중일 때 "멈추기"를 누른다
- **THEN** 첫 번째는 끝까지 하고 나머지 두 줄은 "멈췄어요 · 실행하지 않았어요"가 되며 실행되지 않는다

#### Scenario: 확인 창에서 취소
- **WHEN** 확인 창에서 "취소"를 고른다
- **THEN** 아무것도 실행되지 않고 줄 상태와 선택이 그대로다

#### Scenario: 창이 열린 동안 바뀜
- **WHEN** 확인 창이 열린 동안 터미널에서 그 플러그인 하나를 먼저 업데이트했다
- **THEN** 그 줄은 "건너뜀 · 그사이 바뀌었어요"이고 실행되지 않으며 나머지는 업데이트된다

#### Scenario: 승인이 필요한 것이 섞임
- **WHEN** 두 개 가운데 첫 번째가 추가 명령 승인을 요구한다
- **THEN** 첫 번째 줄에 터미널 안내가 보이고 두 번째는 업데이트된다

#### Scenario: 진행 중 다른 조작
- **WHEN** 한꺼번에 업데이트가 진행 중이다
- **THEN** 체크박스·토글·단일 업데이트 버튼이 잠기고, 명령을 직접 보내도 거절된다

#### Scenario: 15개 상한
- **WHEN** 업데이트 있음이 18개다
- **THEN** "모두 업데이트 (15)"이고 "한 번에 15개까지 해요"가 보이며, 확인 창에 15개가 모두 적힌다
