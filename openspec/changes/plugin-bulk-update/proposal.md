# 플러그인 한꺼번에 업데이트

## Why

사용자 요청: 플러그인을 클릭 한 번으로 업데이트하고 싶다("모두 업데이트", "선택한 것 업데이트"). 지금은 플러그인마다 업데이트 버튼을 누르고 확인 창을 하나씩 넘겨야 한다. 마켓플레이스를 새로 받은 뒤 업데이트가 여러 개 생기면 번거롭다.

## What Changes

- 확장 탭의 플러그인 묶음 머리에 "모두 업데이트 (N)"와 "선택한 것 업데이트 (N)"를 단다.
- 업데이트할 수 있는 플러그인(앱에서 바꿀 수 있는 전역 범위, 업데이트 있음 또는 확인 불가) 줄에 체크박스를 단다. 최신·잠긴(프로젝트·로컬·관리자 범위) 플러그인에는 없다.
- "모두"는 업데이트 있음만 고른다. 확인 불가는 직접 체크해야 들어간다.
- 네이티브 확인 창 하나에 플러그인마다 이름@마켓플레이스·범위·현재 → 새 버전을 적고, 단일 업데이트와 같은 위험 안내(마켓플레이스 코드가 내 권한으로 실행됨, 추가 명령 승인은 하지 않음)를 쓴다.
- 확인하면 하나씩 차례로(병렬 아님) 단일 업데이트와 같은 경로로 업데이트한다. 줄마다 대기·업데이트 중·완료·실패(이유) 상태가 보이고, 하나가 실패해도 나머지는 계속한다. "멈추기"는 지금 것만 끝내고 남은 것을 멈춘다. 끝나면 목록을 다시 읽고 요약 한 줄("3개 업데이트, 1개 실패")을 보인다.
- `-y`·`--accept-command`는 여전히 쓰지 않는다. 승인이 필요한 플러그인은 그 줄에 터미널 안내만 남기고 다음으로 넘어간다.

## Capabilities

### Modified Capabilities
- `plugins-tab`: 업데이트(한꺼번에 업데이트 추가).

## Impact

- core: `plugins::bulk_plan`·`recheck`·`run_bulk`(차례 실행·멈추기·건너뜀), i18n 확인 창 문구.
- shell: 명령 `update_plugins`·`stop_plugin_updates`, 이벤트 `plugin-update-progress`. 단일 `update_plugin`과 한 개 업데이트 도우미를 공유한다.
- webview: 체크박스·머리 버튼·줄 상태·요약, api, mock(업데이트 여러 개), i18n ko/en, vitest.
