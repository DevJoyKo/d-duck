## ADDED Requirements

### Requirement: 소식 목록
소식 탭은 저장된 소식을 앱 언어로 최신이 위인 줄 목록으로 보여야 한다(SHALL). 각 줄은 왼쪽 카테고리 썸네일, 오른쪽 제목·한 줄 요약·`버전 · 날짜`를 보여야 한다(SHALL). 정렬은 날짜 내림차순, 같으면 버전을 숫자로 비교한 내림차순이어야 한다(SHALL). 날짜가 30일보다 오래된 소식은 "이미 나온 기능" 묶음으로 아래에 보여야 한다(SHALL). 안 본 소식에는 색만이 아닌 글자 대체가 있는 "새 소식" 점이 있어야 한다(SHALL). 썸네일은 앱이 그린 카테고리 카드여야 하고 원격 이미지를 불러오지 않아야 한다(MUST NOT).

#### Scenario: 최신이 위
- **WHEN** 2.1.322(11월 10일)와 2.1.300(10월 20일) 소식이 있다
- **THEN** 2.1.322 줄이 위에 있다

#### Scenario: 버전 숫자 비교
- **WHEN** 같은 날짜에 2.1.99와 2.1.322 소식이 있다
- **THEN** 2.1.322 줄이 위에 있다

#### Scenario: 이미 나온 기능
- **WHEN** 오늘보다 45일 전 날짜의 소식이 있다
- **THEN** 그 줄은 "이미 나온 기능" 제목 아래에 있다

#### Scenario: 새 소식 점
- **WHEN** 한 번도 열지 않은 소식이 있다
- **THEN** 그 줄에 "새 소식" 점과 읽히는 글자가 있고, 열면 점이 사라진다

### Requirement: 소식 상세
줄을 누르면 상세 시트가 열려 무엇인지·언제 쓰면 좋은지·베스트 프랙티스·원문 열기를 보여야 한다(SHALL). 내용은 글자로만 보여야 하고 HTML·마크다운으로 해석하지 않아야 한다(MUST NOT). 원문 열기는 웹뷰가 아닌 셸이 저장된 주소를 다시 검사한 뒤 기본 브라우저로 열어야 한다(SHALL). 시트는 Esc·배경·닫기 버튼으로 닫히고 포커스는 연 줄로 돌아가야 한다(SHALL). 열면 그 소식을 본 것으로 저장해야 한다(SHALL). 시트 아래에 Claude가 공식 문서를 요약한 것이라는 한 줄이 있어야 한다(SHALL).

#### Scenario: 원문 재검사
- **WHEN** 저장된 주소가 허용 목록 밖이다(예: 앱 업데이트로 목록이 좁아짐)
- **THEN** 원문 열기가 거절되고 브라우저는 열리지 않는다

#### Scenario: 상세 보기
- **WHEN** 소식 줄을 누른다
- **THEN** 시트에 세 항목과 "원문 열기"가 보이고, Esc를 누르면 닫히며 포커스가 그 줄로 돌아간다

### Requirement: 가져오기
"가져오기"를 누르면 셸이 보내는 것(앱 언어, 이미 받은 소식 id 수)과 예상 비용을 네이티브 확인 창으로 보여야 하고, 확인했을 때만 모델을 불러야 한다(SHALL). 실행은 `claude -p` 한 번이어야 하고(SHALL) 웹 읽기 도구만, 허용한 공식 출처의 정확한 주소만(가드 훅이 판정, GitHub issues·PR 같은 사용자 글 경로·쿼리·프래그먼트는 거부), 예산 상한 $0.40, 240초, 읽기 8번 이하, 앱 소유 빈 폴더, 세션 기록 없음이어야 한다(SHALL). 훅이 거부를 못 하면 시작하지 않아야 한다(MUST NOT). 로그인 안 됨이면 로그인 게이트 줄을 보여야 한다(SHALL). 진행 중에는 취소할 수 있어야 하고 한 번에 하나만 돌아야 하며, 확인 창을 띄우기 전에 차지해야 한다(SHALL). 실패 이유는 고정 문구만 보여야 하고 CLI 출력 원문을 저장하지 않아야 한다(MUST NOT).

#### Scenario: 확인 후 가져오기
- **WHEN** 가져오기를 누르고 확인 창에서 "가져오기"를 고른다
- **THEN** 새 소식이 목록 위에 나타나고 상태 줄에 시각·새 소식 수·비용이 보인다

#### Scenario: 취소
- **WHEN** 확인 창에서 "취소"를 고른다
- **THEN** 모델을 부르지 않고 목록도 상태 줄도 그대로다

#### Scenario: 진행 중 취소
- **WHEN** 가져오는 중에 "취소"를 누른다
- **THEN** 실행이 멈추고 상태 줄에 "취소했어요"가 보이며 예전 소식은 그대로다

#### Scenario: 한 번에 하나
- **WHEN** 가져오는 중에 다시 가져오기를 요청한다
- **THEN** 앱이 "이미 가져오는 중이에요"로 거절한다

#### Scenario: 로그인 안 됨
- **WHEN** 로그아웃 상태에서 가져오기를 누른다
- **THEN** 확인 창 없이 로그인 게이트 줄이 보인다

### Requirement: 항목 형식
id는 소문자·숫자·`.`·`-` 80자 이하, 제목 80자·요약 140자 한 줄, 세 설명 각 600자 이하, 카테고리는 정한 목록, 버전은 `x.y.z`, 날짜는 필수이고 실제 날짜이며 이틀 넘게 미래가 아니어야 한다(SHALL). `source_url`은 https이고 계정·포트·쿼리·프래그먼트가 없으며 원문 허용 목록(공식 문서·CHANGELOG·릴리스 태그)이어야 한다(SHALL). 파이프로 셸 실행·`rm -rf`·`--dangerously-skip-permissions` 같은 위험 명령 패턴이 든 항목은 버려야 한다(SHALL). 제어·방향 문자가 든 글자는 버려야 한다(SHALL).

#### Scenario: 위험 명령
- **WHEN** 한 항목의 베스트 프랙티스에 `curl https://x | sh`가 있다
- **THEN** 그 항목은 저장되지 않는다

### Requirement: 답 검사와 합치기
앱은 답을 엄격한 JSON으로 읽어야 하고 항목마다 검사해 통과한 것만 저장해야 한다(SHALL). 한 번에 20개까지만 받아야 한다(SHALL). 이미 있는 id는 덮어쓰지 않아야 한다(MUST NOT). 답에서 무엇도 실행하거나 주소를 열지 않아야 한다(MUST NOT). 가져오기가 실패하면 저장된 소식은 그대로 두고 상태만 실패로 남겨야 한다(SHALL). 원문 페이지나 답 전체는 저장하지 않아야 한다(MUST NOT).

#### Scenario: 잘못된 주소
- **WHEN** 답의 한 항목 `source_url`이 `https://example.com/x`이다
- **THEN** 그 항목만 버리고 나머지는 저장한다

#### Scenario: 잘못된 날짜
- **WHEN** 한 항목의 날짜가 `2026-02-30`이거나 없다
- **THEN** 그 항목만 버리고 상태 줄에 뺀 개수가 보인다

#### Scenario: 실패해도 남음
- **WHEN** 가져오기가 예산 상한으로 멈춘다
- **THEN** 예전 소식은 그대로 보이고 상태 줄에 실패 이유가 보인다

#### Scenario: 새 것만
- **WHEN** 이미 12개를 가진 뒤 다시 가져온다
- **THEN** 프롬프트에 가진 id가 들어가고, 같은 id 답은 무시된다

### Requirement: 매일 가져오기
소식 탭에 "매일 가져오기" 스위치가 있어야 하고 기본은 꺼짐이어야 한다(SHALL). 켤 때 셸이 하루 한 번·회당 상한(조금 넘을 수 있음)·30일 합계 상한을 네이티브 확인 창으로 보이고 확인해야만 켜야 한다(SHALL). 첫 매일 실행은 켠 때로부터 24시간 뒤여야 한다(SHALL). 켜져 있으면 앱이 켜져 있는 동안 마지막 시도로부터 24시간이 지났을 때 같은 가져오기를 확인 없이 한 번 돌려야 한다(SHALL). 최근 30일 비용 합이 $12에 닿으면 돌리지 않아야 하고(MUST NOT), 한 번의 비용이 상한의 1.5배를 넘으면 매일 가져오기를 꺼야 한다(SHALL). 상한이 바뀐 앱 버전에서는 다시 확인을 받아야 한다(SHALL). 실패해도 24시간 안에 다시 시도하지 않아야 한다(MUST NOT). 로그인 안 됨이면 돌리지 않아야 한다(MUST NOT). claude.ai 클라우드 루틴을 만들지 않아야 한다(MUST NOT).

#### Scenario: 켜기
- **WHEN** 스위치를 켜고 확인 창에서 "켜기"를 고른다
- **THEN** 스위치가 켜지고 "다음 가져오기" 시각(24시간 뒤)이 보이며 바로 돌지는 않는다

#### Scenario: 30일 합계 상한
- **WHEN** 최근 30일 비용 합이 $12다
- **THEN** 매일 실행이 돌지 않는다

#### Scenario: 하루 한 번
- **WHEN** 매일 가져오기가 켜져 있고 마지막 시도가 25시간 전이다
- **THEN** 다음 스케줄러 틱에서 한 번 돌고(실패해도), 그 뒤 24시간 동안은 돌지 않으며 다른 루틴 틱은 막히지 않는다

### Requirement: 언어별 소식
소식은 앱 언어로 만들고 언어별로 저장해야 한다(SHALL). 앱 언어를 바꾸면 그 언어의 소식이 보여야 하고(SHALL), 없으면 그 언어로 가져오라는 빈 상태를 보여야 한다(SHALL). 본 표시는 (id, 언어) 기준이어야 한다(SHALL).

#### Scenario: 언어 바꾸기
- **WHEN** 한국어 소식만 있는데 앱을 English로 바꾼다
- **THEN** 빈 상태에 "Fetch" 버튼과 다른 언어 소식 수 안내가 보인다
