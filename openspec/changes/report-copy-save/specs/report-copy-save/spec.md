# Spec Delta

## Purpose
작업 보고서와 리뷰 탭에서 사람이 읽는 내용을 선택해 복사하고, 에이전트가 남긴 첨부 문서를 파일로 저장하거나 원문을 복사할 수 있게 한다.

## ADDED Requirements

### Requirement: 보고서 내용 선택
작업 보고서 화면과 리뷰 탭 카드의 내용 영역은 마우스로 끌어 선택하고 ⌘C로 복사할 수 있어야 한다(SHALL). 내용 영역은 목표, 판정 줄, 완료 기준과 그 설명, 묻지 않고 정한 결정, 먼저 확인할 것, 근거 설명과 명령·출력, 테스트 요약, Markdown 첨부 본문이다. 버튼, 탭, 칩, 사이드바, 머리말처럼 조작하는 요소는 지금처럼 선택되지 않아야 한다(SHALL). 선택을 시작하려고 끌어도 카드 열기 같은 클릭 동작이 일어나지 않아야 한다(SHALL).

#### Scenario: 완료 기준 복사
- **WHEN** 보고서에서 완료 기준 두 줄을 끌어 선택하고 ⌘C를 누른다
- **THEN** 클립보드에 두 줄의 글이 들어 있다

#### Scenario: 리뷰 카드에서 끌기
- **WHEN** 리뷰 탭 카드의 목표 줄을 끌어 선택한다
- **THEN** 글이 선택되고 카드가 열리거나 리뷰했어요 표시가 바뀌지 않는다

#### Scenario: 키보드로 열기
- **WHEN** Tab으로 리뷰 카드의 "보고서 열기"에 가서 Enter를 누른다
- **THEN** 그 작업의 보고서가 열린다

#### Scenario: 조작 요소는 그대로
- **WHEN** 사이드바 항목이나 버튼 위에서 끈다
- **THEN** 글이 선택되지 않는다

### Requirement: 첨부 저장
첨부 헤더에는 "저장" 버튼이 있어야 한다(SHALL). 누르면 macOS 저장 창이 열리고, 기본 이름은 첨부 파일 이름(`.md`·`.html`)이어야 한다(SHALL). 저장되는 내용은 보고서 폴더의 원본 파일이며, 화면에 보일 때와 같은 읽기 규칙(링크 거부, 일반 파일, 크기 상한, UTF-8)을 통과한 경우에만 저장해야 한다(SHALL). 저장 창에서 취소하면 아무것도 쓰지 않아야 한다(SHALL). 끝나면 "저장했어요"를, 실패하면 이유 한 줄을 보여야 한다(SHALL). 웹뷰가 저장 경로나 내용을 정할 수 없어야 하며(MUST NOT), 저장 위치는 저장 창에서 사용자가 고른 곳뿐이어야 한다(SHALL).

#### Scenario: Markdown 저장
- **WHEN** 리뷰 탭에서 Markdown 첨부를 열고 "저장"을 눌러 다운로드 폴더에 저장한다
- **THEN** 다운로드 폴더에 원본과 같은 내용의 `.md` 파일이 생기고 "저장했어요"가 보인다

#### Scenario: HTML 저장
- **WHEN** HTML 첨부에서 "저장"을 누르고 저장한다
- **THEN** 원본 `.html` 파일이 그대로 저장된다(화면 표시용으로 정리한 버전이 아님)

#### Scenario: 원본이 바뀜
- **WHEN** 첨부를 연 뒤 저장하기 전에 원본 파일이 링크로 바뀌었거나 크기 상한을 넘었다
- **THEN** 저장하지 않고 이유를 보여 준다

#### Scenario: 취소
- **WHEN** 저장 창에서 취소를 누른다
- **THEN** 파일이 생기지 않고 메시지도 뜨지 않는다

### Requirement: Markdown 원문 복사
Markdown 첨부 헤더에는 "복사" 버튼이 있어야 하며 누르면 원문 Markdown이 클립보드에 들어가야 한다(SHALL). 단, 화면 표시와 같이 bidi 제어 문자와 보이지 않는 제어 문자는 빼야 한다(SHALL). 복사가 끝나면 버튼이 잠깐 "복사했어요"로 바뀌어야 한다(SHALL). HTML 첨부에는 복사 버튼이 없다.

#### Scenario: 원문 복사
- **WHEN** Markdown 첨부의 "복사"를 누른다
- **THEN** 클립보드에 `#`·`-` 같은 Markdown 기호가 그대로 있는 원문이 들어가고 버튼이 "복사했어요"로 바뀐다
