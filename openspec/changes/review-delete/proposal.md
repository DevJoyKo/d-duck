# 리뷰 탭에서 지우기

## Why

사용자 요청: "리뷰쪽에 삭제 기능 있어야 할듯". 리뷰 탭에는 이제 보고서 있는 작업, 보고서 없는 작업(D-196), 루틴 실행 보고서가 모두 보인다(review-routine-runs). 다 본 카드나 필요 없는 카드를 치울 방법은 없다. 작업 기록은 작업 탭 "지난 작업"에서만 지울 수 있고, 루틴 보고서는 지울 곳이 아예 없다.

## What Changes

- 끝난 카드(보고서 있는 작업, 보고서 없는 작업, 루틴 실행)마다 "삭제"를 단다. 실행 중이거나 답을 기다리는 카드, 실행 여부를 아직 모르는 카드에는 달지 않는다.
- 삭제는 셸의 네이티브 확인 창을 거친다. 창에는 무엇이 지워지는지(작업 기록·보고서 폴더의 근거·첨부)와 무엇이 남는지(Claude 세션 기록, git worktree·브랜치)를 쓴다. worktree를 쓴 작업이 아직 정리 끝이 아니면 "먼저 작업 탭 정리에서 worktree를 지우세요"를 더한다.
- 작업 기록 삭제는 지난 작업 삭제와 같은 `task_meta::delete_record_and_report` 경로다(기록·지시·보고서 폴더, 다른 기록이 가리키는 폴더는 남김, 지시 흔적 scrub).
- 루틴 실행은 그 실행의 보고서 폴더를 지우고 보고서 연결·리뷰 상태를 비운다. 루틴 실행 기록(언제 돌았는지·상태)은 루틴 탭에 그대로 남는다.
- 지운 뒤 배지·보드 리뷰 대기/정리 칸·리뷰 탭 수가 바로 바뀌고, 포커스는 다음 카드로 간다. 되돌리기는 없다.

## Capabilities

### Modified Capabilities
- `review-inbox`: 카드 삭제.

## Impact

- core: `review_inbox::delete`(실행 중 거절, 작업/루틴 분기), `task_meta`의 보고서 폴더 정리 도우미 공유, i18n 확인 문구.
- shell: 명령 `inbox_delete`(네이티브 확인, confirm_lock).
- webview: 카드 "삭제" 버튼, api, mock, i18n.
