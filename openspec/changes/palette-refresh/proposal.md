# Proposal

## Why

사용자가 지금 색감이 마음에 들지 않는다고 했다. 특히 화면 왼쪽을 꽉 채운 남색 사이드바 띠가 무겁다는 의견이다. 오픈소스 공개 전 첫인상을 다듬는다. 캐릭터는 처음엔 유지하기로 했다가, 다듬은 조약돌 그림체로 바꾸기로 했다(D-177, tasks 2.4). 참고 시안: scratchpad 시안 A "Still Water"의 색 체계.

## What Changes

- **사이드바(rail)**
  - 남색 채움을 없앤다. 라이트는 밝은 중성색 반투명(뒤 흐림), 다크는 흑연색 반투명으로 바꾼다.
  - 선택된 항목은 은은한 바탕과 진한 글자로 표시한다. 왼쪽 강조 막대는 남기되 얇고 중성색으로 바꾼다.
- **색 토큰 교체**
  - 라이트: 잉크 #24283B, 바탕 #F5F6F8, 카드 #FFFFFF
  - 다크: 남색 계열 대신 흑연 계열. 바탕 #1D1E23, 카드 #27282F, 글자 #ECEEF4
  - 상태색(실패·일하는 중·한도)도 같은 체계로 맞춘다. 시안 값 중 대비 4.5:1에 못 미치는 것은 아래처럼 고친다(design-critic HIGH, WCAG 계산).
    - 라이트: ink-3 #6A6F7F, 실패 #CF3338, 일하는 중 #1F7F4B, 한도 #AA5A01
    - 다크: ink-3 #8B90A1, ink-2 #A9ADBB, 실패 #FF6B6F, 일하는 중 #4CC38A, 한도 #F0A24A (카드 #27282F·바탕 #1D1E23 기준 모두 4.6 이상)
  - 오리 노랑 #FFC83D는 그대로 두고, 화면당 강조 한 곳에만 쓴다.
- **위계**
  - 카드 기본 테두리를 0.5px 옅은 선과 낮은 그림자로 바꾼다.
  - 나를 기다리는 카드는 한 단계 높은 그림자와 노랑 링으로 표시한다.
  - 작업 보드 칸에는 테두리 없는 옅은 바탕(well)을 깐다.
- **시안 A의 화면 다듬기**(2단계로 나눔: 이 change는 색·사이드바·위계까지, 타입 스케일·카드 구조·역할 칩은 2.3에서 따로 리뷰)(사용자: "A가 취향")
  - 타입 스케일: 페이지 제목 20, 카드 제목 14, 본문·버튼 13, 메타 12. 페이지 머리에 한 줄 요약을 둔다(예: "답을 기다리는 작업 1개, 리뷰할 작업 5개").
  - 작업 카드의 동작 버튼은 카드 밖에 흩어 두지 않고, 카드 안 아래쪽 구분선 밑으로 모은다.
  - 역할 알약 배지는 줄이고, 작은 오리 칩과 텍스트 메타("개발 · dduck-developer")로 바꾼다.
  - 버튼 체계: primary(잉크 채움, 화면당 1~2개), secondary(옅은 채움), plain(텍스트)
- **바꾸지 않는 것**: 정보 구조와 보드 칸 구성(5칸), 기능

## Capabilities

### New Capabilities
- `visual-palette`: 앱 색 체계(사이드바, 라이트·다크 토큰, 노랑 사용 규칙, 카드 위계)

### Modified Capabilities
- 없음

## Impact

- `app/src/index.css`: 토큰을 바꾸고 rail 관련 토큰과 그림자 토큰을 추가한다.
- `app/src/components/Sidebar.tsx`와 공용 `ui.tsx`(Sheet·Card·Button 기본 클래스)
- 작업 보드 칸
- 남색을 직접 쓴 하드코딩 색(`#222854` 등)을 정리한다.
- 스크린샷 리뷰: 라이트 1440·다크 900, 화면 8개, 대비 4.5:1
